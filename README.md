# Meego Demo

一个轻量的中文任务看板：添加任务、设置优先级、切换完成状态、筛选和删除任务，并显示完成进度。适配桌面和手机，支持键盘操作。

## 本地运行

需要 **Node.js 22 或更新版本**，没有第三方依赖，不需要 API 密钥、数据库或安装依赖。

```sh
npm start
```

默认监听 `127.0.0.1:3000`。开发时使用 `npm run dev` 启用服务端文件监听；前端文件修改后刷新浏览器即可。可用 `HOST` 和 `PORT` 自定义监听地址，例如：

```sh
HOST=0.0.0.0 PORT=3000 npm start
```

## 验证

```sh
npm test
curl --fail http://127.0.0.1:3000/health
```

测试覆盖任务生命周期、输入与本地数据校验、页面和静态资源访问、健康检查及路由限制。项目直接使用浏览器原生模块，无需构建。

## 数据与范围

- 数据保存在当前浏览器的 `localStorage`，刷新后保留；不同浏览器、设备或站点地址之间不共享。
- 没有登录、服务端数据库和多人同步；清除浏览器数据会删除任务。请勿将此演示用作重要数据的唯一存储。
- 本地存储不可用或数据损坏时会显示提示，并保留已有存储，新操作暂存在当前页面。
- 不加载外部字体、脚本或分析服务。

## 目录

- `server.js`：基于 Node.js 内置 HTTP 模块的静态服务及 `/health` 接口。
- `public/`：页面、样式、交互和纯任务数据逻辑。
- `test/`：使用 Node.js 内置测试运行器的测试。

## 云环境

使用 `/workspace/Meego-demo` 现有检出目录，无需创建额外 worktree。运行 `npm test` 后启动 `npm start`，检查 `/health` 和首页响应。发布的环境快照保留文件，但服务进程需要重新启动。
